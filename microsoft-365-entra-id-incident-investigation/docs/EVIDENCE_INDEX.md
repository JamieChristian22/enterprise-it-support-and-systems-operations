## Redaction protocol

1. Browser tabs, address bar and desktop unrelated to task removed by cropping.
2. Account names, email addresses, identifiers, user principal names and local usernames are obscured where visible.
3. No raw screenshots are distributed in the ZIP.
4. Verify screenshots manually again before publishing to GitHub.
5. Never include access tokens, passwords, cookie values, or full correlation IDs in public evidence.
